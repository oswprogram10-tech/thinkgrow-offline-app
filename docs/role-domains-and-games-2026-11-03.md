# 교사 채점 · 학부모 소식 · 게임 설치/실행 연결

2026-11-03. 역할별 소스와 합성 검증 기록이다. 설치 파일은 개발 산출물이며 정식 공개 승인은 계속 별도다.

## 교사

온라인에서 권한이 있는 수업 목록을 받고 선택한 수업의 현재 제출 판본, 문항, 교사용 참고 답안, 평가 기준을 준비한다. 기기에서는 점수/성취 수준·피드백·확정 여부를 암호화 초안으로 저장한다. 저장은 판본 비교 후 적용하며 이전 초안 이력도 남긴다.

온라인 반영은 사용자가 누를 때 수행한다. 서버는 현재 교사 권한, 답안 판본, 기존 채점 판본, 기기 epoch를 재검사한다. 채점과 중복 수신 장부를 같은 트랜잭션에 기록하므로 응답 유실 뒤 재전송해도 채점이 늘어나지 않는다. 다른 채점이나 새 답안이 있으면 기기 초안을 보존하고 충돌로 알린다. 결과는 처음에는 항상 비공개이며 공개는 기존 온라인 화면에서 수행한다.

## 학부모

현재 승인된 자녀 연결, 교사가 공개한 보고서/학습 기록·생활 요약, 현재 연결 차수의 메시지·공지를 기존 온라인 서비스로 조회한다. 연락처·내부 교사 자료를 별도로 확장해 내보내지 않는다. 기기의 서명된 보관 자료는 암호화하며 준비 시각을 표시한다. 연결 해제나 보고서 철회는 다음 온라인 조회에 반영되며, 오프라인 사본을 원격으로 지운다고 주장하지 않는다.

메시지 회신은 기기에 먼저 보관하고 명시적으로 전송한다. 동일 요청 재전송은 메시지와 알림을 중복 생성하지 않는다. 서버는 승인 연결 차수와 기기 epoch를 다시 확인한다. 공지 읽음과 선택 회신은 온라인 작업이며 읽음만으로 동의하지 않는다. 앱 회신은 공식 동의나 법적 전자서명이 아니다.

## 게임

게임 기본 설치 수는 0이다. 교사는 기존 마켓플레이스의 게시·승인·접근 검사를 통과한 게임을 선택한다. 학생은 기기 등록 범위 안의 수업에 교사가 명시적으로 배정한 게임만 준비한다. 배정은 원본 ZIP 해시와 판본에 고정하며, 원본이 바뀌면 새 배정이 필요하다.

현재 실행기는 **오프라인 단독 실행 계약을 선언한 정적 패키지**용이다. 기존 마켓 게임이 모두 이 계약을 지원한다고 판정하지 않는다. 서버형 게임, 임의 실행 파일, 서버/교실 전용 기능은 이 실행기로 자동 변환하지 않는다. 패키지 제작자는 기존 승인 절차에 더해 아래 호스트 계약에 맞춰 게임을 준비해야 한다.

```json
{
  "version": "1.0.0",
  "runtime": {"type": "static"},
  "offline": {"solo": true, "host_api": 1, "entry": "index.html"}
}
```

모든 파일을 패키지에 포함한다. ZIP 및 압축 해제 합계 각각 1 MiB, 개별 파일 512 KiB, 파일 128개 이하를 지원한다. 경로는 영문·숫자와 `-_.~/`만 허용하며 상위 경로, 링크, 중복 경로, 해시 변조를 거부한다. 외부 네트워크·동적 eval에 의존하는 패키지는 이 호스트와 호환되지 않는다.

호스트는 진입 HTML에 `ThinkGrowOffline` SDK를 제공한다.

```js
const context = await ThinkGrowOffline.ready;
// context: run_id, game, assignment_id, checkpoint, last_sequence
await ThinkGrowOffline.emitEvent("progress", {round: 1});
await ThinkGrowOffline.emitEvent("answer", {item: "q1", response: "선택"});
await ThinkGrowOffline.saveCheckpoint({round: 2});
await ThinkGrowOffline.emitEvent("complete", {self_reported_score: 10});
```

기기 실행은 교사 `127.0.0.1:41731`, 학생 `127.0.0.1:41732`의 별도 원점과 실행마다 바뀌는 임의 토큰을 사용한다. 앱 CSP는 해당 역할의 정확한 원점만 frame으로 허용한다. 포트가 사용 중이면 실행을 거부한다. 게임 frame에는 앱 자격·쿠키·키·파일 권한을 전달하지 않는다. frame sandbox와 별도 CSP는 외부 통신·상위 화면 이동·팝업·폼·다른 frame을 제한한다. Android의 평문 통신 예외는 `127.0.0.1`에만 둔다.

실행 중 코드는 메모리에 판본을 고정한다. 이벤트는 순번으로 중복을 구분하며 앱/계정/기기/수업/게임 해시별로 저장한다. 체크포인트와 이벤트는 함께 커밋한다. 게임의 자체 점수는 공식 평가가 아니다. 계정 잠금은 실행 화면과 로컬 호스트를 종료한다. 게임 모듈은 보호 백업에서 제외하고 채점·회신·게임 진행 기록은 포함한다. 손상된 게임 보관함이 다른 수업 자료의 계정 열기를 막지 않도록 상태를 분리한다.

## API와 검증 범위

`POST /api/offline/v1/roles/exchange`는 서명된 기기 자격과 `thinkgrow.role-request.v1` proof를 받는다. 현재 epoch·역할·권한을 확인하고 `thinkgrow.role-reply.v1`으로 응답한다. 요청/응답은 앱·계정·기기·요청 ID에 결속된다. 읽기 전용 보관 자료를 제외한 변경과 준비 작업은 유효 자격을 요구한다.

은퇴한 발급키는 보관 자료 검증에만 남기며 새 역할 응답은 활성 발급키를 요구한다. 역할·게임 요청에서 만료 시각을 관측하면 저장소의 시간 high-water에도 기록해, 벽시계를 되돌려 쓰기 권한을 되살리지 못하게 한다.

합성 검사, Windows 역할별 컴파일, Android 개발 빌드 결과는 [기능 검증 기록](build-evidence/role-domains-2026-11-03.json)을 따른다. 실제 사용자 기록을 열거나 변경하는 검수는 수행하지 않았다. Apple 타깃은 소스 연결 상태이며 Mac/Xcode 빌드 결과가 없다. 서버/교실 게임 실행환경, 학생 제출 수신·교실 relay와 게임 진행의 교사 전송, 정식 서명·업데이트는 후속 범위다.
