기기 상태를 확인하고 있습니다.

저장된 계정 열기

6~12자리 숫자코드입니다. 잠그거나 자격이 만료되어도 작성한 자료는 지워지지 않습니다.

기기 등록하기

온라인 계정으로 등록 코드를 받으세요. 전송이 끊겼다면 같은 계정을 선택해 다시 시도하세요.

PIN 분실 복구

이전에 만든 보호 백업의 암호를 사용합니다. 이 기기에 저장된 계정의 PIN만 바꾸며 자료는 덮어쓰지 않습니다. 백업 암호를 잊었다면 복구할 수 없습니다.

보호 백업 복원

다른 기기에서 암호화 백업을 선택하고 백업 암호와 새 PIN을 입력합니다. 복원 계정은 같은 기기 ID·키를 유지하므로 온라인 등록 코드를 받아 새 epoch로 갱신하세요. 서버가 epoch를 확인하는 요청은 이전 자격을 거부하며, 이전 설치는 오프라인 동안 계속 사용할 수 있습니다.

초안·제출 대기열·수업·첨부를 포함합니다. 현재 백업 크기 제한은 32 MiB입니다. 암호는 백업 복원과 PIN 분실 복구에 모두 필요합니다.

기기 보관함

배정된 게임 준비

배정된 수업 자료

선생님이 수업에 배정한 자료를 기기에 내려받아 확인할 수 있습니다.

배정된 정확한 판본의 자료만 내려받을 수 있습니다.

게임 보관함

기본 설치 게임은 없습니다. 승인된 게임을 개별 설치합니다. 이 실행기는 오프라인 단독 실행을 지원하는 정적 게임용입니다.

진행 기록과 체크포인트는 기기에 보관됩니다. 게임의 자체 점수는 공식 평가 점수로 반영되지 않습니다.

잠금 숫자코드 변경

현재 숫자코드를 확인한 뒤 새 코드를 저장합니다. 변경 후에는 계정이 잠기며 보관 자료는 그대로 유지됩니다.

보호 백업 만들기

현재 PIN을 확인한 뒤 백업 암호로 전체 계정 보관 파일을 암호화합니다. 암호는 이 기기에서 PIN 분실 복구에도 쓰이므로 백업 파일과 함께 안전하게 보관하세요.

내 수업

기기에 준비한 수업을 확인합니다.

기기 등록 때 선택한 수업을 내려받으면 인터넷 없이 작성할 수 있습니다. 새 수업을 추가하려면 등록 코드에서 수업을 선택하고 기존 계정의 자격을 갱신하세요.

도움말

내 답안

제출 대기열의 답안은 서버 수신 확인을 받으면 제출 완료로 바뀝니다. 이후 수정은 새 초안으로 남습니다.

기본 제공 게임은 없습니다. 게임은 마켓플레이스에서 개별 설치하는 방식으로 제공됩니다.
